# 영업ON 인텔리전스 — 데이터 파일 규격

이 폴더의 `*.sample.csv` 는 **샘플 데이터**입니다. 실제 데이터로 교체하려면
같은 컬럼 구조의 CSV 를 만들어 대시보드 화면에서 업로드하거나(권장),
파일명을 `*.csv` 로 두고 `npm run build:sales` 로 시드를 재생성하세요.

> 모든 화면은 데이터 출처(실데이터/샘플/입력/수집)와 신뢰도(A~D)를 배지로 표시합니다.
> 값이 비면 "확인 필요"로 노출되며, 임의로 채우지 않습니다.

## 키 관계
- `account_id` : 거래처 식별자 (거래처마스터 ↔ 납품이력 ↔ 페어링리스트)
- `product_id` : 제품 식별자 = **신동와인 재고표의 품목코드(code)**. 납품이력이 이 코드로 제품마스터(재고 932 SKU)와 조인됩니다.
- 제품마스터는 별도 CSV 가 아니라 기존 `data/inventory.json`(실재고)을 재사용합니다.

## 1) 거래처마스터.csv
`account_id, 거래처명, 사업자명, 채널, 업장타입, 지역1, 지역2, 주소, 위도, 경도, 담당자, 거래상태, 운영시간, 월평균매출, 중요도, 메모`
- 위도/경도 없으면 동선 최적화에서 제외(“주소 필요” 표기)
- 중요도: A(핵심)/B/C/D
- 거래상태 예: 거래중 / 최근매출감소 / 제안진행 / 휴면

## 2) 납품이력.csv
`order_id, account_id, 거래처명, product_id, 브랜드명, 와인명, 빈티지, 출고일, 수량, 공급가, 매출액, 담당자, 채널, 지역, 메모`
- 출고일: `YYYY-MM-DD`
- 입점상태는 출고일로 자동 산출(현재 납품중/최근3개월/6개월+미출고)

## 3) 페어링리스트.csv
`pairing_id, account_id, 거래처명, 메뉴명, glass_type, 가격, wine_order, 와인명, 생산자, 국가, 지역, 품종, 빈티지, 수입사, 신동와인제품여부, 확인일, 확인자, 신뢰도, 메모`
- glass_type 예: `5 Glass` / `7 Glass` / `Bottle`
- 신동와인제품여부: `Y`/`N` (제품마스터와 자동 매칭 후보도 함께 제시)
- 확인일 기준 30/60/90일 경과 시 “재확인 필요” 경고

## 4) 지역선호도.csv
`region_id, 대권역, 세부지역, 업장타입, 선호국가, 선호지역, 선호스타일, 선호품종, 선호가격대, 추천포트폴리오, 데이터출처, 신뢰도, 담당자코멘트`
- 신뢰도 등급: A(실매출/납품) · B(거래처 와인리스트) · C(담당자 코멘트) · D(추정/샘플)
- 데이터출처: 실제 납품 데이터 / 영업사원 입력 / 와인리스트 수집 / 추정·샘플 / 외부 조사 필요

## CSV 작성 주의
- 인코딩 UTF-8, 첫 줄은 헤더(위 컬럼명 그대로)
- 필드 안에 쉼표가 있으면 큰따옴표로 감싸기(`"서울 강남구, 1층"`)
- 모르는 값은 비워두기(→ 화면에서 “확인 필요”). 추측해서 채우지 않기
