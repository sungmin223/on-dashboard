# 운영(실데이터) 입력 폴더

이 폴더의 CSV에 **실제 데이터**를 기입하면, 빌드 시 샘플 대신 이 데이터로 시드가 만들어지고
배포본(모든 사용자)에 그대로 반영됩니다.

## 입력 방법
1. 같은 폴더의 빈 양식(헤더만 있는) CSV를 **엑셀로 열어** 행을 채웁니다.
   - `거래처마스터.csv`, `납품이력.csv`, `페어링리스트.csv`, `지역선호도.csv`
   - 컬럼 의미·예시는 `../samples/README_데이터컬럼.md` 와 `../samples/*.sample.csv`(예시 데이터) 참고.
2. **엑셀 저장 시 형식 = "CSV UTF-8(쉼표로 분리)"** 로 저장하세요(한글 깨짐 방지).
3. 헤더(첫 줄)는 **절대 바꾸지 마세요.** 모르는 값은 비워 두면 화면에 "확인 필요"로 표시됩니다(추측 금지).

## 핵심 키
- `account_id` : 거래처 고유 ID. 거래처마스터에서 정하고, 납품/페어링에서 같은 값으로 연결.
- `product_id` : **신동와인 재고표의 품목코드(code)** 를 그대로 사용 → 재고 932 SKU와 자동 연결(입점검색·대체추천 정확도↑).
- `위도/경도` : 동선 최적화에 필요. 없으면 그 거래처는 동선에서 제외됨(주소만으론 계산 안 됨).
  - 좌표 찾기: 카카오맵/구글맵에서 주소 검색 → 우클릭 "이곳의 정보"/URL의 좌표 확인.

## 일부만 교체해도 됨
4개 중 채운 파일만 운영 데이터로 쓰이고, **비워둔(헤더만 있는) 파일은 자동으로 샘플로 폴백**합니다.
예) 거래처마스터·납품이력만 채우면 그 둘은 실데이터, 페어링·지역선호는 샘플 유지.

## 반영(배포)
```
npm run deploy:sales
```
→ 시드 재생성(`data/sales-seed.json`) + Vercel 운영 배포까지 한 번에.
(시드만 갱신하려면 `npm run build:sales`)

## 보안
이 폴더의 `*.csv` 실데이터는 git에 올라가지 않습니다(.gitignore). 빈 양식과 이 안내서만 저장소에 포함됩니다.
실데이터는 배포본 시드(`sales-seed.json`)에만 구워져 사내 URL에서 비밀번호 로그인 후 조회됩니다.
